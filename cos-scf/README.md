# COS 桶文件夹同步服务（腾讯云 SCF 云函数）

网站「上传图片 / 改名专栏 / 移动图片」都走这个云函数中转：浏览器把图发给函数，
由函数在**服务端**用 COS 密钥签名后直传桶。COS 密钥只存在于函数环境变量，**永不进前端**，
因此访客浏览器完全拿不到凭证，适合面向所有人的公开站点。

- 上传：浏览器 POST 二进制图 → 函数签名后 PUT 到桶 → 返回公网 URL
- 改名 / 移动：服务端复制 + 删旧（旧逻辑不变）

## 部署步骤（手机/电脑浏览器均可）

1. 打开 [腾讯云 SCF 控制台](https://console.cloud.tencent.com/scf) → 函数服务 → **新建**
2. 创建方式：**函数（事件函数）**（**不是 Web 函数！** Web 函数是 WSGI 透传模式，本代码是事件函数格式，不兼容）；运行环境选 **Python 3.10**；模板选 **空白**
3. 把本目录 `index.py` 上传到函数代码（**推荐用「上传文件」而不是粘贴**：手机粘贴 SCF 编辑器会自动加缩进，导致 `IndentationError`；用「上传文件」最稳）；`requirements.txt` 也一并上传（云函数会自动 `pip install` 依赖）。
   - 不想传文件，也可直接下载已校正好的 `index.py`：`https://raw.githubusercontent.com/Mlinkr/MiragedGeist/main/cos-scf/index.py`
4. 进入函数 **函数配置 → 环境变量**，添加四项（**注意是「环境变量」**，不是「标签」）：
   | 键 | 值 |
   |----|----|
   | `COS_SECRET_ID` | 你的 SecretId（用轮换后的新密钥） |
   | `COS_SECRET_KEY` | 你的 SecretKey（用轮换后的新密钥） |
   | `COS_BUCKET` | `miragedgeist-1463128155` |
   | `COS_REGION` | `ap-guangzhou` |
5. 在函数详情页左侧/顶部找到 **「函数 URL」**（和「触发管理」同级），点 **创建函数 URL**：
   - 访问类型：**公网**
   - 认证方式：**无**（免签名，否则浏览器直接调会被拒）
   - 创建后会给出一个 **公网地址**，形如 `https://<appid>-<id>.ap-guangzhou.tencentscf.com`（**不带 `.in.`**）。这就是要填到网站的地址。
   - ⚠️ **执行超时时间改为 60 秒**（默认 3 秒，上传大图/视频会超时失败）。在函数配置 → 基础配置里改。
   - 跨域：函数 URL 默认响应已带 `Access-Control-Allow-Origin: *`，允许 POST/OPTIONS，无需额外配置。
6. 网站里：管理面板 → 底部「COS 中转地址（云函数 URL）」→ 粘贴这个**公网**地址 → 保存。
   同一个地址同时用于「上传」与「改名 / 移动同步」。

> 注意：
> - **不要去「触发管理」建 API 网关触发**，腾讯云 API 网关已迁移，旧触发方式现在建不出来；而且触发器给的多是 `*.in.*` 内网地址，手机公网访问不到。
> - 用「**函数 URL**」拿到的**公网**地址才是对的。老地址带 `.in.` 是内网，白贴。
> - 如果之前误建成了 Web 函数（`Cos_scf`），删掉重建为**事件函数**即可，代码无需改动。

## 接口

### 中转上传（二进制 body）
`POST <地址>?action=upload&key=Photos/<专栏>/<文件名>.jpg&ct=image/jpeg`
请求体为文件**原始二进制**（不是 base64），`Content-Type` 与 `ct` 一致。

- 成功返回 `{"ok":true,"key":"...","url":"https://<桶>.cos.<地域>.myqcloud.com/..."}`
- 前端拿到 `url` 作为图片 `src`、缩略图 `src` 一并上传（小图，同一接口）
- 单文件建议 < 8MB（函数 URL 同步调用对 body 有体积上限，过大请先在前端压缩）

### 改名 / 移动（JSON body）
`POST <地址>` ，JSON body：

- 改名文件夹：`{"action":"rename_folder","old":"旧名","new":"新名"}`
  把 `Photos/<旧名>/` 整目录复制到 `Photos/<新名>/` 并删旧
- 移动图片：`{"action":"move_object","from":"源专栏","to":"目标专栏","file":"文件名.jpg"}`
  把 `Photos/<源>/<file>` 复制到 `Photos/<目标>/<file>` 并删旧

返回 `{"ok":true,...}` 表示成功。

## 说明

- 函数只做「中转直传 / 服务端复制 + 删旧」，不存储任何图片内容，凭证只在服务端，前端零暴露。
- 没填地址时，网站上传会优雅降级到 GitHub / 本机预览；改名/移动只改网页数据、不动桶。
- 复制失败会报错并返回，前端会提示你手动在桶里调整。
