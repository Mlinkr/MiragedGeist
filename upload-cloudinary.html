📤 手机直传 Cloudinary 图床

选图 → 直传 Cloudinary（免费、不用绑卡）→ 生成外链，粘到网站后台「🌐 粘贴外链图片」。 原图与缩略图都按同一张图实时生成：网格用缩略图、点开看原图。配置只存你手机，不上传任何人。
① Cloudinary 配置（首次填，自动存本机）
缩略图由 Cloudinary 实时生成（在 URL 里插入 w_1600,c_limit,q_auto,f_auto），不占额外存储。网格加载缩略图、灯箱看原图。
填了 Worker 地址 → 走签名上传，原画质、任意大小（突破免签名 10MB 限制）；留空 → 退回免签名 preset（≤10MB）。Worker 部署与 Secret 配置见 cloudflare-worker/README.md。
❓ 怎么拿到这些配置（只用手机，不用绑卡）

1. 手机浏览器开 cloudinary.com 注册（邮箱即可，无需信用卡），免费额度 25GB 存储+带宽/月。

2. 进控制台 → Settings → Upload → Upload presets → Add upload preset。

3. Signing Mode 选 Unsigned（免签名），命名如 mlinkr_unsigned，保存。这个预设名就是下面的 Upload Preset。

4. Cloud Name：控制台首页右上角或 Dashboard 里能看到（一串短字母数字）。

5. 回到本页填好，自动记住，下次免填 → 选图上传即可。

6. 复制全部外链，去网站后台进专栏点「🌐 粘贴外链图片」粘贴。每行已是 原图 | 标题 | 缩略图 格式。

生成的链接会显示在这里，点右侧按钮复制单条，或一键复制全部。
