📤 手机直传 腾讯云 COS 图床

选图 → Worker 给一次性预签名 → 手机直传 COS 原画质（不限大小）→ 生成外链，粘到网站后台「🌐 粘贴外链图片」。 原图与缩略图同一张：网格用缩略图、灯箱看原图。配置只存你手机。
① COS 上传配置（首次填，自动存本机）
缩略图由腾讯云数据万象实时生成（URL 里加 ?imageMogr2/thumbnail/1600x），不占额外存储。不用 Cloudflare 也能用：把签名服务部署成腾讯云函数 SCF 即可（见 cos-scf/README.md），或 Cloudflare Worker（见 cloudflare-worker/README.md）。
❓ 前置：桶要开 CORS + 数据万象（电脑/手机浏览器都行）

1. 数据万象：COS 控制台 → 存储桶 → 数据万象 → 开通（缩略图实时缩放依赖它）。

2. CORS：存储桶 → 安全管理 → 跨域访问 CORS → 新增规则：
来源 Origin 填 *（或你的站点域名）；Method 勾 PUT,POST,GET,HEAD,OPTIONS； Allow-Header 填 *；暴露头部按需。保存。

3. 签名服务（二选一，都不用懂代码）：
• 腾讯云函数 SCF（推荐，和 COS 同账号）：把 cos-scf/index.py 部署成事件函数+HTTP 触发，详见 cos-scf/README.md。
• Cloudflare Worker：把 cloudflare-worker/worker.js 部署到 Cloudflare，详见 cloudflare-worker/README.md。
两者都只需填环境变量 COS_SECRET_ID / COS_SECRET_KEY / COS_BUCKET / COS_REGION（SecretKey 只在服务端，不下发手机）。

生成的链接会显示在这里，点右侧按钮复制单条，或一键复制全部。
