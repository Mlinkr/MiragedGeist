📤 手机直传 R2 图床

选图 → 直传 Cloudflare R2 → 生成外链，粘到网站后台的「🌐 粘贴外链图片」。 密钥只存在本机，不上传任何人。建议用一个仅限本桶读写的专用令牌。
① R2 配置（首次填，自动存本机）
公共基址 = 给桶开启「公开访问」后得到的 https://pub-xxxx.r2.dev，或你绑定的自定义域名。对象键会拼在它后面。
❓ 怎么拿到这些 R2 配置（只用手机，不用电脑）

1. 手机浏览器打开 dash.cloudflare.com 登录（无账号先免费注册）。

2. 左侧菜单选 R2 对象存储（首次按提示免费开通）。

3. 点 创建存储桶，名字自取（如 mlinkr-photos），地区选 自动。

4. 进桶后开启 公开访问（Public access），会得到 https://pub-xxxx.r2.dev —— 这就是「公共访问基址」。
进阶：想用自己域名可在桶里绑定自定义域（需域名托管在 Cloudflare），新手先用 .r2.dev 即可。

5. Account ID：R2 概览页 URL 里 cloudflare.com/ 后面那串就是；或在账户主页右侧「API」处复制。

6. 创建专用令牌：R2 → 管理 R2 API 令牌 → 创建：权限选 对象读写，范围（Scope）勾选 仅本桶（只动这一个桶，手机丢了也不怕），创建后立刻保存 Access Key ID 和 Secret（Secret 只显示一次）。

7. 回到本页把上面 ① 六项填好（Secret 只存你手机，不上传任何人），填完自动记住，下次免填。

8. 选图 → 上传并生成外链 → 点「复制全部外链」，再去网站后台进专栏点「🌐 粘贴外链图片」粘贴即可。每行已是 原图 | 标题 | 缩略图 格式，网格自动用缩略图、点开看原图。

费用：存储约 $0.015/GB·月，免费额度 10GB + 每月 1000万次读取；出站流量免费（正是选 R2 的原因）。你单图≤30MB、上千张基本在免费额度内。

缩略图用 JPEG 高质量压缩（长边 1600px / 质量 85），清晰不糊，全平台浏览器都能生成，体积约为原图几分之一。网格加载缩略图、点开看原图，首页不再被 30MB 原图拖慢。
生成的链接会显示在这里，点右侧按钮复制单条，或一键复制全部。
